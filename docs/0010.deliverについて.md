# deliverについて

## 概要

stockdbで使っているfastapiで作成したapiサーバ。  
port 8080で待ち受け。

| 項目 | 設定値 |
| --- | --- |
| IPアドレス | 192.168.0.154 |
| 待ち受けポート | 8080 |
| url | http://192.168.0.154:8080 |

## systemctlで起動を管理

サービス名`deliver`でsystemctlに登録済。

### serviceファイルのパス

```bash
cat /etc/systemd/system/deliver.service
```
